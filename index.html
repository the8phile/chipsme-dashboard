Connect Google Sheet (Permanent Fix)
Set up once — syncs instantly forever

    


    

      Why this fixes the sync: Google blocks direct requests from websites (CORS). Apps Script creates YOUR OWN private API that has no restrictions. Takes 3 minutes to set up.
    


    

      

        
1

        
Open your Google Sheet
Go to Extensions → Apps Script

      

      

        
2

        
Delete everything, paste this code:

          
function doGet(e){
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sh = ss.getActiveSheet();
  var data = sh.getDataRange().getValues();
  var cb = e.parameter.callback || "callback";
  var json = JSON.stringify(data);
  var output = cb + "(" + json + ")";
  return ContentService.createTextOutput(output)
    .setMimeType(ContentService.MimeType.JAVASCRIPT);
}
